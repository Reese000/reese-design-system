Design Principles
Active
1. Maximized Action Space
Buttons are large, tappable, and always visible. Primary actions get XL (52px) buttons. Secondary actions get LG (44px). Nothing is smaller than 28px. Every action has a visible keyboard shortcut.
2. Zero Hidden Menus
All features exist on screen simultaneously. Toolbar buttons, action grids, inspector panels — everything is one click or one keypress away. Progressive complexity through color, not through nesting.
3. Semantic Color Coding
13 distinct color categories map every type of action and data. Blue = actions, red = danger, green = success, amber = warning, cyan = materials, orange = tools, purple = config, pink = data, lime = viewports, magenta = AI.
4. Keyboard-First Navigation
Ctrl+K opens a command palette for instant access. Shortcuts displayed inline on every button. Focus rings on all interactive elements. Tab order follows visual hierarchy.
5. Density Without Clutter
Information-dense panels use color, spacing, and subtle borders to separate — not cards within cards. Monospace for data, proportional for labels. Tabular alignment for numbers.
6. Dark-Mode Native
Built for dark mode first. Near-black canvas with luminance-stepped surfaces. Semi-transparent white borders. Never pure black or pure white. Eyes stay comfortable during long sessions.

Implementation Guidelines

Rules
✓ DO
✓ Use XL (52px) buttons for primary actions
✓ Show keyboard shortcuts on every button
✓ Color-code categories consistently across all apps
✓ Use monospace for all numeric/data values
✓ Place the most-used actions in the top-left toolbar
✓ Use status dots + pills for state communication
✓ Enable Ctrl+K command palette in every application
✓ Use the 6-level surface luminance scale for depth
✓ Apply tabular-nums for aligned number columns
✓ Use semi-transparent white borders on dark surfaces
✓ Keep all features visible — no hamburger menus on desktop
✓ Use the inset shadow for recessed/pressed elements
✗ DON'T
✗ Hide features behind dropdown menus
✗ Use color decoratively — every color has meaning
✗ Mix color categories (orange for data, blue for tools)
✗ Use proportional fonts for numeric data
✗ Make buttons smaller than 28px (SM size)
✗ Use pure black (#000) or pure white (#fff) for text
✗ Add gradients or glassmorphism to functional UI
✗ Use bold (700) weight for body text — 600 max
✗ Create nested cards (cards inside cards)
✗ Use positive letter-spacing on body text
✗ Force users to remember where features are
✗ Add decorative icons that don't improve scanning
